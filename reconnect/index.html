Reconnect — Scowtt Internal Finance

Effective date: October 5, 2026

Use this page when Intuit asks Scowtt to reconnect the private finance integration (for example before a refresh token's long-term expiry).

Steps:

  1. Sign in with the Scowtt QuickBooks Online admin account.
  2. Approve "Scowtt Internal Finance" again when prompted.
  3. Tell Madhu (madhuj@scowtt.com) that reconnect finished so Scowtt can store the new tokens.

If the Connect button is not yet live on this page, Madhu will send you the current Connect link from the Intuit Developer portal / OAuth Playground.
